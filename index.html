KI-Werkzeuge direkt in Claude und ChatGPT

Ein MCP-Dienst ist ein Connector. Du trägst die Adresse einmal ein, meldest dich an und nutzt das Werkzeug danach direkt im Chat.

Pilot / Zugang auf Anfrage

KI-Zielgruppensimulation

KI-Personen reagieren auf ein Angebot, einen Namen oder eine Kampagne. Danach werden sie befragt, die Antworten im Code ausgezählt, jede Frage mit neutraler Gegenprobe. Ergebnis: ein Stimmungsbild mit Einwänden in etwa einer Stunde.

Keine echten Befragten, keine Prognose.

https://simulation.neher.ai/mcp

Dashboard: simulation.neher.ai. Verwendet die Open-Source-Software MiroFish (AGPL-3.0). Keine Verbindung zum offiziellen MiroFish-Projekt.

So verbindest du einen Dienst

  1. In Claude oder ChatGPT einen eigenen Connector hinzufügen.
  2. Die Adresse von oben einfügen.
  3. Mit deinem Konto anmelden und den Zugriff erlauben.

Konten werden in der Pilotphase einzeln freigeschaltet. Anfrage an klaus@neher.ai.
